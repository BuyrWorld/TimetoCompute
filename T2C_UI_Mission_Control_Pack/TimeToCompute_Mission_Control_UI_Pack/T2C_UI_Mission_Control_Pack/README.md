# TimeToCompute — Mission Control UI Pack

This pack translates the approved TimeToCompute visual direction into an implementation brief for Claude Code.

## Contents

- `CLAUDE_CODE_PROMPT.md` — the complete prompt to paste into Claude Code.
- `DESIGN_SYSTEM.md` — visual tokens, layout rules, responsive behaviour and accessibility requirements.
- `INTERACTION_MAP.md` — the intended destination and behaviour of every interactive homepage element.
- `references/01-home-mission-control.png` — Today / Mission Control visual reference.
- `references/02-company-intelligence.png` — company intelligence visual reference.
- `references/03-site-intelligence.png` — individual site visual reference.

1. Extract this folder into `C:\Users\joshu\OneDrive\Desktop\T2C\T2C_UI_Mission_Control_Pack`.
