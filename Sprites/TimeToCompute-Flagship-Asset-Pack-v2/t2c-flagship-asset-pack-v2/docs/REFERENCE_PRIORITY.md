## Conflict rule

When two references conflict:

1. Real data integrity and existing working behaviour win.
2. v2 page hierarchy wins over earlier layout details.
3. Production tokens and manifests win over sampled screenshot colours.
4. Accessibility and responsive behaviour win over pixel-level imitation.
